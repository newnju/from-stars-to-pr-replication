### 灰度约定（全刊图通用）

《新闻与传播研究》内页为黑白印刷，四张图一律按灰度设计，不依赖颜色区分：

| 元素 | 色值 | 说明 |
|---|---|---|
| 数据系列（一级） | `#1A1A1A` | 主墨色 |
| 数据系列（二级） | `#6E6E6E` | 中灰 |
| 数据系列（三级） | `#B8B8B8` | 浅灰 |
| 参考线（等价界、三成、随机基线） | `#8C8C8C` | 虚线，比数据线浅一档 |
| 辅助线（时间刻度） | `#CCCCCC` | 点线 |
| 主文字 / 次文字 | `#1A1A1A` / `#333333`、`#666666` | — |

**不要用颜色编码类别**。此前图 3(a) 用橙 `#DD6B20` 与绿 `#38A169`，转灰度后分别是 133 与 124，几乎相同，黑白印刷下分不出；已改为 `#6E6E6E` 与 `#B8B8B8`。

## 四、正文与封面

```bash
cd paper_figs/docx_build
node generate_xwycbyj.js     # → %TEMP%\xwycbyj.docx
node generate_cover.js       # → 投稿封面_20261031.docx
```

### `content13.json` 字段

| 字段 | 说明 |
|---|---|
| `title` / `subtitle` / `title_en` | 主标题、副标题、英文标题 |
| `abstract` / `abstract_en` | 中英文摘要 |
| `keywords` / `keywords_en` | 关键词 |
| `blocks[]` | 正文块，`t` ∈ {`h1`,`h2`,`p`,`fig`,`table`,`ref`}，`x` 为文字或图表 id |
| `refNotes` | 编号 → 该刊格式的注释文本（`*…*` 表示斜体） |
| `figures` | 图注 `caption`、图下说明 `note` |
| `tables` | 表题 `caption`、表格数据、表下说明 `note` |

> `t: "ref"` 为文末参考文献条目，小五号、悬挂缩进 2 字。**《新闻与传播研究》采用注释体例，不设文末参考文献表**；
> 该节仅为其他投稿渠道或送审需要保留，投该刊时应整节删除（删 `blocks` 末尾的 `参考文献` h1 及其后全部 `ref` 块）。

### 引注写法（生成器内部标记）

- `[[REF:12]]` 或 `[[REF:12,27,32]]` → 生成页下注，编号对应 `refNotes` 的键，多条用“；”连接
- `[[FN:……]]` → 曾用于生成说明性页下注，**现已全部迁出**，正文不再使用

页下注**每页独立编号**（①②③），由 `sectPr` 的 `numRestart=eachPage` 控制。

## 六、已知限制

1. **Python 沙箱不能写 E:**，所有脚本输出先落 `%TEMP%`，再手工拷回项目。这是环境限制，不是脚本缺陷。
2. **图 2—4 的输入是中间聚合文件**（`fig_input_*.json`），不是从 raw 直接算。要全链路复现，需先跑 `analysis/fetch_*.py` 与相应聚合脚本。
3. **表 1—4 的数字未自动回填**：改动了 `data/results/` 里的结果后，需手工同步 `content13.json` 的 `tables` 字段。
4. **旧图 1 代码已停用**：`make_journal_figures.py` 中原有的链式图段落替换为注释，图 1 只由 `make_fig1_framework.py` 生成。
