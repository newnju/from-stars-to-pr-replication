# 第十轮综合数据挖掘报告（2026-10-29）

**范围**：对项目全部已采集数据做系统性挖掘。新增四层专用分析（fork→PR 终值、PR 评论、SKILL.md 历史、跨层整合），并与前九轮 80 余项挖掘衔接。
**数据底座**：35,947 仓普查 / 155,547 份文档 / 五渠道平台 / 225 父仓 183 万 fork（447,495 回流 PR 事件）/ 45,360 条 PR 及 61,078 条评论 / 684 侧 SKILL.md 历史。
**产出**：`mine_comprehensive_20261029.json`（全部数字）；脚本 `analysis/mine_comprehensive.py`（一键复算，45 秒）。

## A. fork→PR 终值层（225 父仓，447,495 个回流 PR 事件）

| # | 发现 | 数字 |
|---|---|---|
| A1 | 回流 PR 的结局结构 | 合并 44.8%、关闭未合并 40.9%、仍开启 14.3%；**已结案者中合并率 52.3%** |
| A2 | 合并速度极快、关闭极慢 | 合并中位 **7.7 小时**（p90 196h）；关闭未合并中位 **98.9 小时**（p90 70 天） |
| A3 | 回流时距呈**双峰**而非单峰 | <1h 占 **27.9%**、1–24h 合计 36.9%；7 天以上合计 52.0%（7–30d 15.7%、30–90d 15.3%、90–365d 13.7%、>1y 7.3%）——「立即同步」与「长期不回」两个世界 |
| A4 | 回流作者集中度 | 99,797 名作者，Gini **0.719**；单人最多 6,594 个回流 PR（vincentkoc）；父仓内 top1 作者份额中位 10.9% |
| A5 | 父仓转化率呈长尾+双峰 | 中位 3.89%、p90 15.2%；直方图 0–1%:24 仓、1–2%:46、2–5%:68、5–10%:41、10–20%:31、20–40%:9、>40%:5；**12 个父仓（5.4%）贡献一半回流 fork** |
| A6 | 事件量的生态节奏 | 2011–2025 长期爬坡（月事件从个位数到 4 千级），2026 年爆发：2026-03 起月均 3–5 万，2026-09 峰值 52,819 |
| A7 | 转化率与仓特征**无关** | conversion ~ log10(星标)+log10(fork)+年龄：R²=**0.007**；星标 Spearman ρ=0.06（p=0.37）——注意力完全不预测贡献转化 |
| A8 | 各仓合并率差异巨大 | 父仓合并率中位 48.2%，p10 7.6%、p90 79.1% |

**读法**：P2「采纳—贡献弱耦合」从"低转化"升级为"**结构化分层**"——多数仓近零转化，少数同步流水线仓高转化，且转化与注意力无关；回流时间「要么 1 小时内、要么永远」的断崖形态进一步否定"深思熟虑贡献"叙事。

## B. PR 评论层（45,360 条 PR / 61,078 条评论，162 仓）

| # | 发现 | 数字 |
|---|---|---|
| B1 | 评论覆盖两极化 | 45.1% 的 PR 零评论；29.0% 单条；22.2% 2–5 条；**4.2% 六条以上** |
| B2 | 响应极快、把关贴脸 | 首条评论中位 **1.8 分钟**（p90 10 天）；合并前最后一条评论距合并中位 **52 分钟** |
| B3 | 人类评论文本画像 | 中位 537 字符（p90 5,865）；代码块 10.9%、URL 29.0%、请求句式 60.5%、肯定句式 54.1%、中文 1.9%、≤25 字符 4.1% |
| B4 | **评论式把关也是单点** | 有 ≥10 条评论的 120 仓中，top1 评论者份额中位 **57.9%**（p90 84.2%）——与「64.8% 仓单一账号执行九成合并」互证 |
| B5 | 审查记录形态 | 26,446 条 COMMENTED vs 5,741 APPROVED、2,065 CHANGES_REQUESTED、148 DISMISSED——**"留言"是"正式决定"的 4.6 倍**；review 正文空 32.8% |
| B6 | 有评论的合并且慢 10 倍 | 合并前有评论的 PR 合并时滞中位 **6.45h** vs 无评论 **0.59h**（Mann-Whitney p≈0）——评论确实构成摩擦，但发生在少数 PR 上 |
| B7 | 机器人占比修正 | 机器人评论 **10.81%**（6,601 条；dependabot 462、github-actions 5,923、codecov 214 等），机器人评论更短（中位 451 vs 537 字符） |

**读法**：P4 的"评论式把关"可观测后呈现三层结构——多数合并零把关（A5 交叉：严格口径下 53.2% 合并且无审查无评论）、评论把关集中在少数人（B4）、正式审查以"留言"形式空转（B5）。合并不是被审出来的，是被"过"出来的。

## C. SKILL.md 文件历史层（684 侧）

| # | 发现 | 数字 |
|---|---|---|
| C1 | 技能文档基本"一次写成、不再维护" | 每文件提交数中位 **1**（p90 5、最大 62）；中位存续期 0 天（单提交文件占多数） |
| C2 | 署名字段的主要构成 | 诞生即写：license 140、author 70、source 5；后补仅 11 例（author 7、license 5、source 2）——署名几乎只在诞生时写入 |
| C3 | 署名与维护强度无关 | 有署名 vs 无署名文件的提交数中位均 1（p=0.31）——写不写署名不影响维护行为 |
| C4 | 复制后几乎不再编辑 | 272 对复制对中，子侧提交数多于父侧者仅 **13.6%**；父/子提交中位均 1——复制是"一次性拿走" |

**读法**：P3「复用—溯源不对称」的生产端机制再加一层：文档生命周期本身极短（一次写成），署名窗口只在诞生瞬间，之后既不补写、也不因复制而变化。

## E. 与论文五命题的衔接

- **P2 升级**：转化率"低"改写为"结构化双峰 + 与注意力无关 + 时间断崖（<1h 或 >7d）"。新增 A3/A5/A7 三项证据，全部支持"回流是同步管道而非贡献承诺"。
- **P3 加强**：C1–C4 表明文档一次写成、署名只写在诞生、复制后不再编辑——"生产端稀薄"机制闭环。
- **P4 加强**：B4/B5/D4 给出"单点评论 + 留言式审查 + 过半无把关"的三层把关形态；B6 显示评论虽有摩擦效应但覆盖面小。
- **P5 保持**：D3 平台命中与回流无关，与"收录不由星标/质量预测"一致。
- **未变**：P1（渠道弱相关）不在本轮数据范围内，维持既有结论。

## F. 限制与不可判

1. 回流事件含部分自动化账号（A4 top10 中 roboclaw-bot 2,183 条）——已按登录名识别机器人（10.8% 评论、回流 PR 侧约 0.9–1%），但"人类账号跑自动化"不可判别。
2. 评论长度的中位 537 字符受 2026 年 AI 代理评论风格影响，不能当作"讨论深度"的绝对标尺。
3. B6 的时滞差是相关而非因果：被评论的 PR 本身更复杂。
4. C 层样本为 342 对精确复制对（分层非随机），维持既有口径。
5. D2 的 Spearman 数值见 JSON（面板交集 n 较小时仅作方向参考）。
