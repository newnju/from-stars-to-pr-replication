## 一、SKILL.md 文件历史与署名写入时间（P3 父—子方向性检验）

**采集**：342 对跨仓精确复制对（165 对方向样本 + 177 对由精确复制分组扩展，每仓≤3 次）×2 侧 = 684 侧文件的**全部提交历史**，并对每个版本探测 frontmatter 署名字段（ATTRIB_KEYS 与 `probe_four.py` 一致：license/licence/source/author/attribution/credit/reference/based-on/based_on/original）的**首次写入提交与时间**。
脚本 `analysis/fetch_skillmd_history.py`；原始数据 `E:\temp\opencode\skillmd_history.jsonl`（684 行，0 错误）。

**覆盖**：272/342 对两侧历史完整可判（544 侧）；86 侧无提交历史（多为空壳镜像仓）成对剔除；另有 11 侧署名后补、162 侧诞生即写（含被剔除对）。

### 核心结果

| 检验 | 结果 | 口径 |
|---|---|---|
| 方向可判性（文件首创时间） | 与既有最早提交判定（direction_commits）**116/116 一致** | 管线复现校验，非新证据 |
| 署名写入时序 vs 方向 | 可比 68 对全部一致；其中平凡一致（两侧皆诞生即写）60 对，**非平凡 8/8 一致** | 非平凡 = 至少一侧署名非诞生即写 |
| 父侧署名写入早于子侧文件出现 | **68/70 = 97.1%**（Wilson 95% [90.2%, 99.2%]） | 有署名的复制对 |
| 署名写入时点（544 侧） | 诞生即写 **26.8%**、后补 **1.8%**、从未写 **71.3%** | 全部可判侧 |
| 沿方向保留：父有署名 → 子保留 | **68/70 = 97.1%**（Wilson 95% [90.2%, 99.2%]） | ⚠️ 精确复制对（同 SHA），保留率天然偏高，须与 4,000 对近重复样本的条件保留率 77.8%（含修改对）分列 |
| 复制时滞 | 中位 **17.95 天**，p90 61.19 天（n=225 对） | 父→子文件首创时间差 |

### 可写入论文的表述（P3 由“部分支持”→“确认性支持”）

1. **方向可判**：SKILL.md 文件历史可稳定给出父—子方向，与最早提交判定完全一致（116/116）；在署名可比的复制对上，署名写入时序与文件首创方向一致（68/68，其中非平凡 8/8）。
2. **署名写在生产端、且几乎不事后补写**：署名字段 71.3% 从未写入、26.8% 在文件诞生即写、仅 1.8% 后补——“来源信息在生产端即稀薄”获得时间戳级证据；复制环节的署名丢失不能归因于“后补失败”。
3. **复制不磨损署名**：有署名的复制对中 97.1% 沿方向自父侧先写、子侧保留（复制时滞中位 18 天、p90 61 天）。“复用—溯源不对称”的机制因此定位为**生产端不写**，而非**流转端磨损**（后者是“复写新闻业”路径，本生态不支持）。

## 二、PR 评论全文与评论式把关（P4）

**采集**：治理层面板 164 仓全部 PR 的评论（issue comments）与审查记录（reviews）全文＋时间戳，GraphQL 分页（每页 20 PR × comments first:25 + reviews first:10）。
脚本 `analysis/fetch_pr_comments.py`；原始数据 `E:\temp\opencode\pr_comments.jsonl`。

**覆盖**：**162/164 仓、45,360 条 PR**、61,078 条评论（2 仓 404 永久缺失：libukai/awesome-agent-skills、tradecatlabs/vibe-coding-cn，按口径不计零）；45,360 含 10-24 快照后新建 PR，比 45,203 快照略多。152 条 PR 评论线程超过 25 条被截断标记（不影响覆盖与时序指标）。

### 核心结果

| 检验 | 结果 |
|---|---|
| PR 有任何评论 | 54.9%（24,902/45,360） |
| **PR 有合并前评论** | **52.1%**（全量 23,631）；已合并 PR 中 **38.0%**（9,168/24,134） |
| PR 有任何正式审查 | 33.2%（全量）；已合并 38.4%（9,269/24,134，与既有口径 37.61% 同量级） |
| **仅评论、无正式审查** | **28.6%**（12,958 条 PR）——非正式把关独立可观测 |
| 已合并 PR 把关形态 | 评论+审查 22.8%、**仅评论 15.2%**、仅审查 15.6%、**两者皆无 46.4%** |
| 评论时序 | 首评距创建中位 **0.081 天（约 2 小时）**，p90 20.4 天；合并前评论占全部评论 37.4% |
| 评论者结构 | 机器人 10.8%（6,605），人类 89.2%（54,473） |
| 评论覆盖随仓规模 | 小/中/大三分位：35.7% → 40.1% → **53.7%**（对照正式审查覆盖 5.8%→26.2%） |

### 可写入论文的表述（回应“非正式审查不可观测”）

1. **非正式审查可观测且与正式审查同量级**：合并前评论覆盖 38.0% 对正式审查 38.4%；15.2% 的合并**只有**评论式把关痕迹。把关是双轨的：评论轨与审查轨规模相当、重叠有限（双轨仅 22.8%）。
2. **把关整体仍稀薄**：46.4% 的合并既无合并前评论也无正式审查——“审查形式失效”命题在评论层面同样成立（P4 结论加强而非削弱）。
3. **评论把关同样随规模上升**：35.7%→53.7%（三分位），但基数高于正式审查轨——规模—把关关系是“双轨同升、审查轨恒低”。
4. **节奏特征**：首评中位 2 小时、机器人仅 10.8%——评论以人类快速往返为主，符合“例行化吸收”而非“深思熟虑审查”的刻画。

## 三、限制与口径警示（引用前必读）

1. 方向样本为分层样本（mirror/original 优先、每仓≤3 次），**非总体**；比率均为样本内。
2. 保留率 97.1% 出自**精确复制对**（内容同一），与近重复样本 77.8% 条件保留率口径不同，二者不可混用；精确复制对的保留率上界性质更强。
3. “署名写入时序一致”68/68 中 60 对为平凡一致（两侧署名皆诞生即写，写入时间≡首创时间），非平凡一致仅 8 对——应报分解，勿只报 100%。
4. PR 评论线程 >25 条者截断（152 条 PR）；“全文”对 99.7% 的 PR 成立。
5. 评论与审查的状态字段（review state=COMMENTED 等）计入“有审查”，与论文既有 reviewDecision 口径略有差别，引用时注明。
6. 两项采集均与 fork→PR 采集并行运行，REST 侧限速让量（配额地板 250），未影响 fork 采集推进。
