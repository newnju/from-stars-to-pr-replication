## 规律一：一切重尾，且三组量的尾指数 ≈ 2

| 量 | α（MLE） | x_min | 尾部 n | KS | 优于对数正态（ΔLL） |
|---|---|---|---|---|---|
| 回流 PR/作者 | **2.03** | 39 | 1,184 | 0.033 | −371 |
| 父仓 PR 事件 | **1.99** | 1,226 | 60 | 0.056 | −19 |
| 合并时滞（小时） | **2.21** | 223 | 1,500 | 0.069 | −230 |
| 父仓回流 fork | 2.41 | 647 | 47 | 0.084 | −20 |
| 评论线程长度 | 3.19 | 9 | 888 | 0.128 | −176 |
| 评论字符 | 3.39 | 13,644 | 1,457 | 0.025 | −620 |

**数学含义**：α<2.1 的三组量理论方差发散——"平均仓""平均作者""平均合并时间"在统计上没有意义，必须用中位数/分位数或对数尺度表述。所有被检量都明显偏离指数分布（泊松/几何的连续类比），幂律在各组都优于对数正态。

## 规律二：两个时间尺度——宏观趋势 + 微观批处理

- **宏观**：日事件序列自相关 lag1–14 全在 0.92–0.98（667 天，均值 569 件/日），Fano 因子 615（泊松为 1）——序列被趋势支配。
- **微观**：仓内间隔时间的变异系数 **1.98–103**、爆发度 B 0.33–0.98。hermes-agent（CV=103，B=0.981）、openclaw（CV=9.0，B=0.80）的事件以批处理方式到来——像脚本同步，不像人类逐个操作；playwright（CV=1.98，B=0.33）最接近人类节奏。
- **节律弱但显著**：小时分布 3.0%–5.0%（峰 9 时 UTC、谷 23 时）；周末占 11.1–11.2% vs 工作日 15–16%（降约 30%）。χ² 因样本极大而显著，效应量很小。

## 规律三：合并有两条车道——评论=慢车道，审查=快车道，机器人=捷径

| 分组 | KM 中位合并时滞 | 对数秩 χ²（p≈0） |
|---|---|---|
| 无评论 | **5.4 小时**（n=20,458） | — |
| 有评论 | **367 小时** | 2,701 |
| 无正式审查 | 70.4 h | — |
| 有正式审查 | **52.0 h** | 158 |
| 人类作者 | 66.1 h | — |
| 机器人作者 | **20.9 h** | 41 |

Cox（按仓聚类稳健 SE，收敛警告见限制）：has_comment 系数 **−0.689**（降低合并风险）、has_review **+0.309**（提高），均 p<1e-6。解读必须是"伴生"而非"导致"：评论标记的是争议/复杂 PR，审查标记的是走流程的常规 PR。

## 规律四：合并结果几乎不可预测——门槛没有可用准则

- 静态特征（PR 编号、标题长度、中英文、前缀规范、标签数、机器人）：**AUC 0.531**（五折：0.483–0.575，几乎随机）。
- 加入创建后 24h 内的评论/审查数：**AUC 0.590**（折间 0.513–0.709）。
- 置换重要度：PR 编号 0.212（时代/顺序代理）> 24h 评论数 0.144 > 24h 审查 0.070 ≈ 标签数 0.068 > 标题长度 0.061。
- **数学含义**：合并决定携带的可预测信息极少。若把关有准则，这些准则基本没有反映在任何可观测元数据里。

## 规律六：评论者网络是"灌木"而非"枢纽"

- 4,538 名人类评论者中 **93.9% 只出现在一个仓**；跨仓跨度中位 1、p90 1、最大 28。
- 度分布重尾（α=3.78）但离散样本尾部仅 37 人、KS 0.51——只作方向性描述。
- 回流 HHI 中位 0.032（不集中），p90 0.126——多数仓的回流来自很多不同的人，少数仓被单人主导。

## 规律七：人类评论有六种话语，AI 评审已占近两成

TF-IDF+KMeans（30,000 条）：

| 簇 | 占比 | 特征词 |
|---|---|---|
| 行政式收尾 | **34.7%** | thanks / closing / review / please / main |
| 通用代码审查 | 30.6% | test / with / not / only / are |
| **AI 评审摘要** | **17.4%** | summary / coderabbit / walkthrough / generated |
| 安全审计话语 | **10.8%** | tools / evidence / security / audit / detected / corpus |
| 打包跳过 | 3.4% | bundle / skipping / tracked / already |
| CLA 签署 | 3.1% | cla / hereby / sign / signed |

## 规律八：配对估计——有评论的 PR 合并慢 5.06 倍

仓内按 PR 编号近邻 1:1 配对（3,668 对 / 96 仓）：Δlog(时滞) 中位 **1.621**，bootstrap 95% CI [1.47, 1.74] → **exp = 5.06×［4.35×, 5.71×］**。配对控制了仓级差异与时代（编号邻近），但未控制 PR 复杂度，故仍属伴生估计；与规律三构成一致的"评论=慢车道"图像。

## 规律九：回流时距双峰断崖（前一轮终值数据的复述）

<1 小时 27.9% + 1–24h 9.1% + 7d 以上 52.0%——回流要么瞬时（同步脚本），要么极迟（或永不），中间地带薄。

## 数学工具适用性小结

**适用**：幂律 MLE+KS（重尾）、爆发度/Fano（点过程偏离泊松）、KM/logrank/Cox（删失时间）、GroupKFold 交叉验证（防仓内泄漏）、k-means/GMM+轮廓/BIC、IsolationForest、TF-IDF+KMeans、仓内配对+bootstrap。

**不适用（数据会拒绝）**：泊松假设（Fano 615）、均值+标准差比较（α≤2.1 方差发散）、把转化率当连续正态变量做 t 检验（双峰重尾）、把"有评论→慢"直接读成因果（选择效应未控）。

**限制**：Cox 报告收敛警告（时变系数/重尾所致，系数方向可信、量级谨慎）；评论语言以英文为主（中文 1.9%）；文本聚类受 2026 年 AI 评审机器人话语影响；配对未控制 PR 复杂度。
